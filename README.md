# daapu

Name generated by https://uniq.site/

This is a web-based LLM chatbot with a per-instance shared memory system.

The bot runs as a small stack (see `compose.yaml`): a PostgreSQL database with
the pgvector extension and a Kotlin/Ktor backend that serves both the REST API
and the React frontend as static assets. Chat conversations are managed by
[koog](https://docs.koog.ai)'s `ChatMemory` feature, persisted through a
Postgres-backed `ChatHistoryProvider` — see `AGENTS.md`.

## Deployment

### Prerequisites

- Docker + Docker Compose
- A reverse proxy (Nginx/Caddy) in front of the app for TLS — the backend speaks
  plain HTTP on port 8080 and does not terminate TLS itself.

### Single-instance

There is deliberately **no multi-instance support** yet. The stack is meant to
run exactly one instance; two instances sharing the same PostgreSQL database
will cause desync. Single-instance-per-deployment is the operator's responsibility.

### Configuration

Configuration is read from environment variables (in development, place these in
a `.env` file; under Docker Compose they are provided via `env_file`):

| Variable             | Required | Description                                                                 |
|----------------------|----------|-----------------------------------------------------------------------------|
| `DATABASE_URL`       | yes      | JDBC URL for PostgreSQL, e.g. `jdbc:postgresql://localhost:5432/postgres`.  |
| `DATABASE_USER`      | yes      | Database user.                                                              |
| `DATABASE_PASSWORD`  | yes      | Database password.                                                          |
| `SESSION_COOKIE_KEY` | yes      | HMAC-SHA256 secret used to sign the session cookie.                         |
| `LLM_API_KEY`        | yes      | LLM provider API key (OpenAI-compatible).                                   |
| `LLM_BASE_URL`       | no       | LLM provider base URL. Defaults to `https://api.openai.com`.                |
| `LLM_MODEL`          | no       | LLM model id. Defaults to `gpt-4o-mini`.                                   |
| `LLM_SYSTEM_PROMPT`  | no       | System prompt for the agent. Defaults to `You are a helpful assistant.`     |

Note: under Docker Compose, `DATABASE_URL` is overridden in `compose.yaml` to
point at the `db` service (`jdbc:postgresql://db:5432/postgres`), so the `.env`
file can use `localhost` for local development.

## Development

### Backend

Run the database, then start the Ktor backend:

```bash
docker compose up -d db
./gradlew run
```

The backend listens on `http://localhost:8080`.

### Frontend

From `frontend/`, run the Vite dev server (proxies `/api/*` to the backend on
port 8080):

```bash
npm install
npm run dev
```

The frontend dev server listens on `http://localhost:5173`.

### Verification

Backend:

```bash
./gradlew test
```

Frontend (from `frontend/`):

```bash
npm run typecheck
npm run lint
npm test
```
