# XmppKt

This module provides the logic to support the main chatbot on XMPP protocol with OMEMO encryption.

This module largely reuse the [Smack](https://github.com/igniterealtime/Smack/) components like
smack-core, smack-tcp, etc. And only rewrite the parts that fail to satisfy this project.

About the license, the original code is Apache 2.0 and GPL v3, this project is AGPL, so should be fine.
